# AIPal · AI 游戏搭子

一个常驻在屏幕角落的语音陪玩：你打游戏时按一下热键说话，它听懂、用语音回你，还能顺手看一眼你的屏幕，并且记得上一局聊了什么。

全部在本机跑，聊天记录和密钥只存在 `%APPDATA%\AIPal`，不上传。

## 它由三件事组成

| 环节 | 默认通道 | 是否花钱 |
|---|---|---|
| 听（语音识别） | Windows 本机离线识别 | 免费，无需 Key，断网可用 |
| 想（对话） | 任意 OpenAI 兼容接口 | 需自填接口，硅基流动有免费额度 |
| 说（语音合成） | 微软 Edge 朗读接口 | 免费，无需 Key |

三条都可以在设置里换成你自己的云端接口。

## 快速开始

1. 双击 `AIPal.exe`（便携版，免安装）
2. 点小窗齿轮 → **连接自检**，耳朵和嘴直接检测即可通过
3. **大脑**填接口与 Key：
   - 地址 `https://api.siliconflow.cn/v1`
   - 模型 `Qwen/Qwen2.5-VL-7B-Instruct`（要看懂画面必须选多模态模型）
   - 不确定模型名就点「拉取可用模型」，从清单里点一个
4. 保存并生效，回小窗按热键（默认 `F8`）说话，或者打开「自动听」

## 功能

- 热键说话 / 自动听两种触发，随时打断她
- 截图看画面（按需附带，不常驻录屏）
- 记住你让她记的事、常玩的游戏、最近的对话
- 识别当前前台游戏窗口（只读窗口标题，不注入进程）
- 软件内检查更新，便携版可直接替换重启，不用重新下载

## 已知边界

- 游戏开「全屏独占」时 Windows 会挡住所有悬浮窗，请改成「窗口化无边框」
- 本机离线识别在安静房间够用，开黑噪音大会掉字，可换云端识别
- 自动更新的仓库公开，检查更新受 GitHub 匿名限流影响，失败会走 releases.atom 兜底

## 开发

```bash
npm install
npm start
```

打包便携版见 `scripts/` 与构建脚本；发布时把 `AIPal-<version>-portable.zip` 传到 GitHub Releases，软件内的更新按钮就会读到它。
