AIPal v0.1.0

连接自检

三条通道各点一下，确认真能用再开局。任何一条不通，她会当场哑火。

耳朵未检测

本机离线识别：免费、无 Key、断网可用

大脑未检测

需要填一个 OpenAI 兼容接口和 Key

嘴未检测

Edge 免费语音：无需 Key，直接出声

免费怎么玩：耳朵用本机识别、嘴用 Edge 免费语音，这两条不需要任何 Key； 只有大脑要一个模型接口（硅基流动注册后送免费额度，或者接本机 Ollama）。

大脑 · 对话模型

兼容 OpenAI 的 /chat/completions，硅基流动、火山方舟、DeepSeek、Ollama 都能填。

手填模型名最容易出错，建议直接拉一份真实清单来选
想看画面就得选支持图片的模型（硅基流动的 Qwen2.5-VL、Qwen2-VL 等）。 纯文本模型也能聊，但"看屏幕"会失败。

耳朵 · 语音识别

本机识别用的是 Windows 自带中文识别引擎，安静房间里够用，开黑有噪音时会掉字。 识别不准就换云端，硅基流动的 SenseVoice 有免费额度。

嘴 · 语音合成

语速范围大致 -50% ~ +100%，音调 -50Hz ~ +50Hz。 嫌她太吵就把语速调到 +20%，一句话更快说完。

角色卡

她还会自动知道：你现在在玩什么、你常玩哪些游戏、你让她记过的事、当前是几点。

交互

游戏开了全屏独占时，Windows 会挡住所有悬浮窗。把游戏改成「窗口化无边框」，她就一直待在你屏幕角落。

记忆

她记得的事都存本机。你可以直接对她说"记住我不吃辣"这类话，让她写进来。

版本与更新

更新包从 GitHub Releases 取。便携版可以直接在软件里替换，不用重新下载整个包。
